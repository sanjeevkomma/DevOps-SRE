# Definition
* HashiCorp Nomad is a lightweight, flexible, and scalable orchestrator used to deploy and manage containers and non-containerized applications across multiple environments (Linux, Windows, macOS, VMs, and bare-metal)
# What is Nomad?
* A single binary that handles scheduling and workload orchestration.
* Supports Docker, Java, exec, raw_exec, qemu, etc.
* A great alternative to Kubernetes when you want simplicity, performance, and ease of setup.
