# Definition
* HashiCorp Nomad is a lightweight, flexible, and easy-to-use workload orchestrator.
* It’s used to deploy and manage applications (containers, VMs, JARs, etc.) across on-premises and cloud environments
* HashiCorp Nomad is a lightweight, flexible, and scalable orchestrator used to deploy and manage containers and non-containerized applications across multiple environments (Linux, Windows, macOS, VMs, and bare-metal)
* Think of it like a simpler, more flexible alternative to Kubernetes. It supports:
   * Docker, Java JARs, binaries, QEMU, and VMs
   * Multi-datacenter, multi-region clusters
   * Integration with Consul (for service discovery) and Vault (for secrets)
  
# What is Nomad?
* A single binary that handles scheduling and workload orchestration.
* Supports Docker, Java, exec, raw_exec, qemu, etc.
* A great alternative to Kubernetes when you want simplicity, performance, and ease of setup.
