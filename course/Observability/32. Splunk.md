
# 📊 Splunk Overview

## 🔍 What is Splunk?

**Splunk** is a **log analysis and monitoring tool** used to collect, index, search, and visualize machine-generated data in real time from various sources like:

- Applications
- Servers
- Cloud infrastructure
- Security devices
- IoT devices

---

## 🛠️ What Splunk Does

1. **Ingests Logs & Metrics**
   - From sources like web servers, apps, Kubernetes, AWS CloudTrail, etc.

2. **Indexes the Data**
   - Converts raw log data into searchable events.

3. **Search & Query**
   - Uses a custom language called **SPL (Search Processing Language)**.

4. **Visualization**
   - Create dashboards, graphs, alerts, and reports.

5. **Alerting**
   - Sends notifications for anomalies or threshold breaches.

---

## 💡 Common Use Cases

| Use Case              | Example                                 |
|------------------------|------------------------------------------|
| Monitoring             | Track API latency or HTTP 500 errors    |
| Security (SIEM)        | Detect unauthorized access or brute force |
| DevOps                 | Debug production issues from logs       |
| Compliance             | Store and audit logs (e.g., PCI, HIPAA) |
| Alerting               | Alert when disk space < 10%             |

---

## 🔎 Example SPL Query

```spl
index=prod_logs sourcetype=apache_access status=500
```

This finds all HTTP 500 errors from Apache logs in the `prod_logs` index.

---

## 🧱 Splunk Components

- **Universal Forwarder** – Agent to send logs from servers
- **Indexer** – Stores and indexes the data
- **Search Head** – UI to run queries and create dashboards
- **Splunk Enterprise** – On-prem solution
- **Splunk Cloud** – Managed SaaS version

## ✅ Summary

- Splunk is ideal for real-time log analysis, monitoring, alerting, and security.
- It supports custom dashboards and automation.
- Available both as on-premise (Enterprise) and SaaS (Cloud).
