# How to Trace a Dependency in Gradle

**Goal**: Identify which part of the project pulls in `com.apple.ap.services:toro-lib-services-model:3.0.0-SNAPSHOT`.

---

## 🔍 Step 1: Use `--dependencyInsight`

Run this command in your terminal:

```bash
./gradlew dependencyInsight --dependency toro-lib-services-model --configuration compileClasspath
```

### Optional:
To check other configurations:

```bash
./gradlew dependencyInsight --dependency toro-lib-services-model --configuration runtimeClasspath
```

---

## 🧼 Step 2: Remove or Override the Dependency

### ✅ To Exclude It Globally

Add this block to your `build.gradle`:

```groovy
configurations.all {
    exclude group: 'com.apple.ap.services', module: 'toro-lib-services-model'
}
```

---

### ✅ To Force a Specific Version

If you need to force a version across the project:

```groovy
configurations.all {
    resolutionStrategy {
        force 'com.apple.ap.services:toro-lib-services-model:3.1.0'
    }
}
```
