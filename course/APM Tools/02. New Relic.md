# ToRead
* New Relic is an application performance monitoring (APM) and observability platform
* It helps you monitor, debug, and understand what’s happening inside your applications and infrastructure in real time

# Why It’s Used
* Companies use New Relic to:
     * Monitor application performance
     * Detect errors and crashes
     * Track API response times
     * Monitor servers and cloud infrastructure
     * Analyze logs
     * Set alerts for issues
     * Visualize system health with dashboards


# Example Scenario
* Imagine your API suddenly becomes slow
* New Relic can show:
    * Which endpoint is slow
    * Which database query is causing delay
    * CPU/memory usage
    * Error rates
    * Exact request trace

# What It Monitors
# 1. APM (Application Performance Monitoring)
* Java, Node.js, Python, .NET, etc.
* Tracks transactions
* Shows response time breakdown
# 2. Infrastructure Monitoring
* CPU
* Memory
* Disk
* Kubernetes
* Cloud services (AWS, GCP, Azure)
# 3. Logs
* Centralized logging
* Searchable logs
# 4. Browser Monitoring
* Frontend performance
* Page load time
* JS errors
# 5. Alerts & Dashboards
* Custom dashboards
* Slack/email alerts
* Incident management

# How It Works
1. Install New Relic agent in your app
2. It collects telemetry data
3. Sends data to New Relic
4. You view it in dashboard or query using NRQL or NerdGraph

# Key Terms
| Term                 | Meaning                            |
| -------------------- | ---------------------------------- |
| NRQL                 | New Relic Query Language           |
| NerdGraph            | GraphQL API for New Relic          |
| License Key          | Used to send data                  |
| APM                  | Application Performance Monitoring |
| Synthetic Monitoring | Fake users testing your site       |
