# Examples of IaC Tools
| Tool                            | Language                 | Description                            |
| ------------------------------- | ------------------------ | -------------------------------------- |
| **Terraform**                   | HCL (HashiCorp Language) | Cloud-agnostic, declarative            |
| **AWS CloudFormation**          | JSON / YAML              | AWS-native declarative IaC             |
| **Pulumi**                      | TypeScript, Python, etc. | Uses real programming languages        |
| **Ansible**                     | YAML (Playbooks)         | Also used for configuration management |
| **Chef / Puppet**               | Ruby DSL                 | Configuration + provisioning           |
| **CDK (Cloud Development Kit)** | TypeScript, Python, etc. | AWS-native, uses real code             |
