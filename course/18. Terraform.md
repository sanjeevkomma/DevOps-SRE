# To Read
* Terraform is Infrastructure as Code tool(IaC)
* Terraform is declarative
* Terraform can provision the resources/infrastructure (compute,database,storage,networking) in multiple clouds ( AWS, AZure, GCP ) 

# Set Up Your Environment
* [Install Terraform CLI](https://developer.hashicorp.com/terraform/install)

# Learning Resources

# Sample File: main.tf
```tf
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "my_ec2" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
}
```
