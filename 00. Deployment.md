# Deployment Types / Kubernetes Deployment Strategies / Zero Downtime Deployment Types

| :--- | :--- | :--- |
| 1| Canary Deployment |1. Rolling it out to a subset of users before rolling out to all users<br>2. Canary deployments allow organizations to test in production with real users and use cases and compare different service versions side by side<br>3. It's cheaper than a blue-green deployment because it does not require two production environments<br>4. Canary deployment exposes a small percentage of users to the new version initially, which means that they may encounter issues as you iterate on the release  |
| 2| Blue/Green Deployment (Red/Black Deployment) | 1. Environment isolation between old & new application versions<br>2. Blue-green deployments are an all-or-nothing approach |
