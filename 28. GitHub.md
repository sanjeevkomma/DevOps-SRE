# Terminology
* SSH = Secure Shell

# GitHub Setup in Local
1. Open Git Bash GUI
2. $ ssh-keygen -t ed25519 -C sanjeevkomma@gmail.com 
3. $ eval "$(ssh-agent -s)"
4. $ ssh-add ~/.ssh/id_ed25519
5. $ clip < ~/.ssh/id_ed25519.pub
6. Open / Add GitHub SSH Keys
7. Add key generatd in ../.ssh folder
